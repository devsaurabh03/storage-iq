StorageIQ Privacy Policy

Smart, Privacy-First Android Storage Intelligence
Effective Date: October 10, 2026

1. Core Privacy Architecture & Zero Cloud Uploads

  • 100% On-Device Storage Processing: All file scanning, SHA-256 duplicate cryptographic hashing, perceptual dHash photo similarity calculations, and storage growth tracking execute exclusively on your local device CPU and hardware.
  • Zero Server Uploads: Your photos, videos, personal documents, downloads, and messaging media never leave your phone. We do not maintain any cloud servers or external media databases.

2. Data Collection & Analytics

  • No Personal File Mining: StorageIQ does not log, analyze, transmit, or monetize your filenames, photo contents, document text, or folder paths.
  • Privacy-Preserving Telemetry: Optional product telemetry tracks only high-level UI interaction states (e.g., scan_completed, category_opened) to improve performance. Personal identifiers and file paths are strictly excluded.

3. Android Permissions & Access Scope

  • Standard MediaStore Access: StorageIQ requests official Android granular media permissions (READ_MEDIA_IMAGES, READ_MEDIA_VIDEO, READ_MEDIA_AUDIO) to categorize your media files.
  • No Intrusive Access: StorageIQ never requests root privileges, Accessibility Services, SMS, contacts, location, call logs, or camera hardware access.

4. Transparent User Control & Deletion Safety

  • No Automatic Deletion: StorageIQ never deletes files silently or automatically. Every file removal requires your explicit selection and confirmation.
  • Native OS System Confirmation: File removals delegate directly to Android system APIs (MediaStore.createDeleteRequest), prompting native OS dialogs before moving items to system Trash.
